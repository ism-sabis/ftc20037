## Accessibility Statement

This website is committed to ensuring digital accessibility for all users, including those with disabilities. We aim to comply with the **Web Content Accessibility Guidelines (WCAG) 2.2 Level AA** standards.

---

## Conformance Status

This website partially conforms with WCAG 2.2 Level AA as it meets some but not all success criteria at this level. We are actively working to address remaining accessibility barriers.

### What we have done:
- Implemented visible focus indicators on all interactive elements
- Ensured keyboard navigation works across the site
- Provided alt text for images and descriptive labels for icons
- Maintained sufficient color contrast ratios (4.5:1 for normal text, 3:1 for large text)
- Respected user preferences for reduced motion via `prefers-reduced-motion`
- Used semantic HTML structure with proper heading hierarchy
- Provided a skip navigation link for keyboard users
- Ensured touch targets meet minimum size requirements (44x44 CSS pixels)

### Known limitations:
- The 3D model viewer may have limited keyboard accessibility in some browsers
- Gallery lightbox focus trapping is implemented but may not cover all edge cases
- Some third-party services (e.g., AR features) may not be fully accessible
